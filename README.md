# Поиск самого высокого супергероя (superhero-api)

В проекте реализована функция `get_tallest_hero(gender: str, has_work: bool)`, которая обращается к Superhero API и возвращает самого высокого супергероя по заданным критериям пола и наличия работы, а также набор автотестов к ней.

## Структура проекта

- `app/main.py` — реализация функции `get_tallest_hero` и получения данных из API.
- `tests/test_superheroes.py` — позитивные, негативные, проверяющие граничные случаи автотесты и тесты с подменой данных через `monkeypatch`.
- `requirements.txt` — необходимые внешние библиотеки (`pytest`, `requests`).
- `pytest.ini` — конфигурация `pytest` для корректного импорта модулей из корня проекта.

## Детали реализации и результаты анализа API

Перед написанием функции был проведен анализ данных из эндпоинта `/all.json`, в ходе которого были выявлены и учтены следующие особенности датасета:

1. Вместо поочередного опроса героев по ID используется один запрос к `/all.json`, чтобы минимизировать сетевые накладные расходы.
2. Единицы измерения: 
   - в метрическом поле роста (`appearance.height[1]`) данные встречаются как в сантиметрах (`cm`), так и в метрах (`meters`). Для точного сравнения метры переводятся в сантиметры;
   - в датасете обнаружена ошибка данных: у героини *Dagger* вместо роста в метрической системе указан вес (`52 kg`). Такая записть а также герои с неизвестным ростом (`0 cm`, `-`), отфильтровываются.
3. Наличие работы (`has_work`) определяется по полю `work.occupation`. Если значение равно `"-"` или пустой строке — герой считается безработным (`False`), в остальных случаях — трудоустроенным (`True`).
4. Валидация входных данных:
   - входной параметр `gender` нечувствителен к регистру и пробелам по краям (значения, встречающися в базе: `"male"`, `"female"`, `"-"`);
   - для проверки `has_work` используется строгая проверка `type(has_work) is not bool`, так как в Python тип `bool` является подклассом `int`, и обычная проверка через `isinstance(1, bool)` не защищает от передачи `True/False` как `1/0` при проверке `int`.

## Установка и запуск тестов

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите тесты из корневой папки проекта:

```bash
pytest -v
```
